Spreadsheet (CSV / Excel): one question per row with a header row: 

class, subject, question, option_a, option_b, option_c, option_d, answer, explanation

The answer is the letter A, B, C or D. The class is SS1, SS2 or SS3: every question must belong to one class. subject, class and explanation can be left out of the file when you pick the subject and class above.

Pictures and diagrams: add an image column holding the picture's file name (e.g. circuit1.png) and attach that picture in the “Pictures” box above.

Shared information (a reading passage, table, map or diagram for several questions): give those questions the same label in a passage column (P1, MAP1…). On the first question of the group also fill passage_title, passage_text and/or passage_image. The questions are always given to students together, in the order they appear in your file.

Download a CSV template.

Text / pasted: one question per line, separated by |:

question | option A | option B | option C | option D | answer letter

Pasted text and .txt files cannot carry pictures or passages, and always need the class chosen above; use a spreadsheet for those. Passage labels are kept separate for each subject and class, so the same label (P1) can be used again in another class. Subjects must match the registration names exactly (e.g. “English Language”, “Further Mathematics”). Each question needs four different options.
